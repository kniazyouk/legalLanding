│ Concepto React #1: COMPONENTE FUNCIONAL                    │
│                                                           │
│ const Navbar = () => { ... }  ->  es un componente de      │
│ React: una función que devuelve JSX (HTML escrito dentro   │
│ de JavaScript). Después se exporta con export default      │

│ cada elemento único.                                      │
│                                                           │
│ Concepto React #3: className                             │
│ En React usás className en vez de class (porque class es   │
│ palabra reservada de JavaScript).                         │
│                                                           │
│ Concepto Tailwind #1: UTILIDADES DE LAYOUT                │
│ sticky top-0 -> el navbar queda pegado arriba al hacer    │
│   scroll                                                   │
│ z-50 -> queda por encima del resto de capas               │
│ bg-white/90 -> blanco con 90% de opacidad                 │
│ backdrop-blur -> desenfoca lo que pasa por detrás         │
│ flex items-center justify-between -> distribuye logo,      │
│   links y botón en horizontal con el logo a la izquierda   │
│   y el botón a la derecha                                  │
│ hidden lg:flex -> los links se ocultan en mobile y        │
│   aparecen en pantallas grandes (lg y más)                │

  export default App

┌────────────────────────────────────────────────────────────┐
│ Concepto React #9: COMPOSICION DE COMPONENTES             │
│                                                           │
│ App() es el componente RAÍZ. No tiene HTML propio,        │
│ solo ORGANIZA otros componentes (Navbar, Hero, Services,   │
│ Footer). Esto es la base de React: interfaces hechas de    │
│ piezas reutilizables.                                     │
│                                                           │
│ <> ... </>  ->  Fragmento de React. Agrupa varios          │
│ componentes SIN agregar un <div> extra al DOM.            │
│ <main>  ->  envoltorio semántico para el contenido         │
│   principal (bueno para accesibilidad y SEO).             │

RESUMEN DE CONCEPTOS QUE APRENDISTE
══════════════════════════════════════════════════════════════════

  REACT:
  #1  Componente funcional              -> Navbar, Hero, etc.
  #2  Renderizado de listas (.map())    -> links, servicios, social
  #3  className (vs class en HTML)      -> en todos lados
  #4  JSX (mezclar HTML y JS)           -> { } para expresiones
  #5  Datos como array + render         -> services, socialIcons
  #6  SVG inline (iconos de marcas)     -> Facebook, X, LinkedIn, YouTube
  #7  Props desestructuradas            -> { name, Icon } en los arrays
  #8  Comentarios en JSX {/* */}        -> documentar bloques
  #9  Composición + fragmentos (<></>)  -> App.tsx como raíz
  #10 export default / import           -> pasar piezas entre archivos

  TAILWIND:
  #1  @theme -> colores propios (bg-navy, text-navy...)
  #2  Responsive (sm, md, lg, xl)       -> grid-cols-4, text-6xl
  #3  Modifiers (hover:)                -> hover:shadow-lg
  #4  Opacity (/90, /70, /15)           -> capas y acentos suaves
  #5  Flexbox / Grid                    -> navbar, cards, footer
  #6  Posicionamiento absoluto          -> foto + overlay del hero
  #7  Sombra y bordes (shadow-md, rounded-full) -> cards y botones

  FLUJO COMPLETO DEL PROYECTO:
  App.tsx (raiz) -> Navbar + Hero + Services + Footer
  Cada componente recibe solo datos; los estilos viven en
  Tailwind (index.css define la paleta con @theme).
